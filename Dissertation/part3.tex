\section{Анализ эффективности}
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

Важной частью работы над программами для численного моделирования является анализ её эффективности.

Эффективность распараллеливания для модуля \verb|RRSPH_OMP| рассчитывается по следующей формуле:
%
\begin{equation}
    E(M) = \frac{S(M)}{M},
\end{equation}
%
где $M$ --- количество потоков, 
а $S$ --- ускорение, вычисленное по формуле ниже:
%
\begin{equation}
    S(M) = \frac{T(1)}{T(M)},
\end{equation}
%
где $T$ --- время выполнения программы с заданным количеством потоков.

В качестве теста выбран расчёт линейных волн, описанный в пунктах \ref{sec:dis_err} и \ref{sec:dis_fade}:
оценивается время, затраченное на выполнение 100 шагов по времени.
%
Тесты проведены на процессоре Intel Core i9-13900F: 
8 производительных ядер (16 потоков), 
16 энергоэффективных ядер (16 потоков).

График зависимости ускорения от количества потоков представлен на рисунке~\ref{f:speedup}. 
%
Точками обозначены результаты измерений, через них проведена кривая регрессии.
%
Наклонная прямая представляет собой теоретическое, линейное ускорение $S(M)=M$.
%
Вертикальная прямая в виде точек обозначает общее количество логических ядер для используемого процессора (32).
%
Горизонтальная прерывистая линия обозначает максимальное ускорение, 
которое удалось достичь на используемом процессоре: $S(128) = 14.466$. 
%
В целом, при $M>M_{\text{max}}$ результаты в задаче массового параллелизма, как данная, зависят от планировщика.
%
\begin{figure}[h!]
    \centering
    \includegraphics[width=0.7\textwidth]{images/Speedup.png}
    \caption{Зависимость ускорения $S(M)$ расчёта от количества потоков $M$}
    \label{f:speedup}
\end{figure}

На рисунке~\ref{f:efficiency} представлен график зависимости эффективности распараллеливания от количества потоков.
%
Точками обозначены результаты измерений, через них проведена кривая регрессии.
%
Горизонтальная линия обозначает теоретическую максимальную эффективность распараллеливания.
%

    \label{f:efficiency}
\end{figure}

Модуль \verb|RRSPH_CL| невозможно запустить в одном потоке или каким-либо образом изменить количество потоков, 
исполняющих его вычислительные ядра.
%
Возможно измерить ускорение, которое достигается с его использованием в сравнении с ускорением \verb|RRSPH_OMP|.

Тест проведён на GPU NVidia RTX 4070 Ti.
%
Получено ускорение $S(\text{GPU}) = 14.057$, что приблизительно равно максимальному ускорению, полученному на процессоре.

Приведённые выше замеры сделаны при использовании чисел с плавающей запятой двойной точности (64 бит),
но графические ускорители оптимизированы для применения чисел с одинарной точностью (32 бит).
%
Разработанный пакет программ возможно пересобрать с использованием заданной точности.
%
Лучшие результаты ускорения по отношению к времени расчёта в одном потоке процессора с одинарной точностью следующие: 
$S_{\text{FP32}}(128) = 11.857$, $S_{\text{FP32}}(\text{GPU}) = 23.241$.

Получаем, что при использовании двойной точности, 
максимальное ускорение используемых вычислительных устройств аналогичное;
при одинарной --- максимальное ускорение видеокарты вдвое превосходит ускорение процессора
(однако одинарная точность зачастую недопустима и ведёт к значительным ошибкам в продолжительных расчётах).

\section{Погрешности в дисперсионном соотношении}\label{sec:dis_err}

При моделировании гравитационных волн на поверхности воды, 
применяется поршень с уравнением движения второго порядка (\ref{eq:nwm_2nd}).
%
Входными параметрами модели являются длина волны $L$, высота волны $H$ и начальная фаза генератора $\phi_{0}$.
Глубина $d$ определяется поиском по частицам перед началом эксперимента.
%
Расчётный модуль определяет по данным параметрам волновое число:
%
\begin{equation}\label{eq:k_from_L}
    k = \frac{2 \pi}{L}
\end{equation}
%
и далее, через дисперсионное соотношение ниже определяет частоту:

\begin{equation}\label{eq:dis1}
    \omega^{2} = gk \tanh(kd).
\end{equation}

%

\section{Анализ затухания волн на поверхности воды}\label{sec:dis_fade}
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

На рисунке~\ref{f:dis_x_l3_t30} можно увидеть, что амплитуда волн снижается при удалении от источника.
%
Это связано с диссипацией, которая в SPH-моделях является особенно сложной из-за присутствия различного рода
численных диссипативных членов (например, искусственной вязкости).

Проведена серия численных экспериментов с целью определения характера затухания волн.
%
В качестве исходного уравнения для пространственного профиля гравитационных волн используется следующее выражение:
%
\begin{equation}
    \eta(x)=A_{0} e^{-\psi x} \cos (kx + \phi_{1}) + d,
\end{equation}
%
где $\psi$ --- коэффициент затухания, зависящий от множества параметров.

Для каждого эксперимента выполняется следующая обработка:
\begin{enumerate}
    \item построены временные профили поверхности на разном удалении от источника волн;
    \item с помощью временных профилей рассчитываются амплитуды волны, характерные для данного удаления от источника
        (для простых случаев достаточно использовать один пространственный профиль, 
        однако анализ множества пиков позволяет более точно определить амплитуду);
    \item найденные амплитуды $A^{*}(x)$ представляются в логарифмированном виде $\ln(A^{*}(x))$;
    \item проводится линейная регрессия, чтобы определить наклон прямой --- это будет искомый коэффициент $\psi$.
\end{enumerate}

На рисунке~\ref{f:dis_xexp_l3_t30} представлена зависимость уровня жидкости в заданный момент времени от координаты
для одного из расчётов.
%
В правой частиц рисунка находятся неустановившиеся, первые волны, которые не вписываются в основную модель 
(аналогичным образом, из регрессии исключается левая часть профиля поверхности, находящаяся в непосредственной
близости от генератора волн).

Здесь стоит обратить внимание на снижение коэффициента затухания $\psi$ с увеличением длины волны.
%
Наименьший коэффициент затухания достигается при наибольшей длине волны --- в модели, 
где распространяется единственная волна с бесконечной длиной, солитон (генератор с уравнением~\ref{eq:nwm_solitary}).
%
Полученные значения значительно превосходят аналитическое значение кинематической вязкости ($\nu_{0} = 10^{-6}$ $\text{м}^2/\text{с}$),
однако это связано с численными диссипативными членами --- в частности, с искусственной вязкостью.
%
Связь между кинематической вязкостью и искусственной вязкостью имеет вид~\cite{Monaghan2005, Amaro2021}:
%
\begin{equation}
    \nu_\text{art} = \frac{\alpha h c_{0}}{2(\text{dim} + 2)},
\end{equation}
%
где $\alpha$ --- коэффициент искусственной вязкости,
$h$ --- длина сглаживания,
$c_{0}$ --- искусственная скорость звука,
dim --- число измерений.
%
При заданных параметрах (таблица~\ref{t:params_dis}) $\nu_\text{art} = 0.01565$ $\text{м}^2/\text{с}$, 
что согласуется с рассчитанным значением вязкости в экспериментах.
