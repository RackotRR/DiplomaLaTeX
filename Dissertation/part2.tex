\chapter{Архитектура и реализация программного комплекса для моделирования поверхностных волн методом SPH}

Программный комплекс для решения задач вычислительной гидродинамики методом сглаженных частиц (SPH) 
обладает модульной архитектурой и состоит из следующих основных компонентов:
%
\begin{enumerate}
    \item вычислительный модуль (\verb|RRSPH|), включающий несколько реализаций с различными методами параллелизации:
        \begin{itemize}
            \item \verb|RRSPH_CL| (реализация на OpenCL);
            \item \verb|RRSPH_OMP| (реализация на OpenMP);
        \end{itemize}
    \item модуль визуализации:
        \begin{itemize}
            \item \verb|SPH2D_Drawer| (2D-визуализация);
            \item \verb|Scatter3D| (3D-визуализация);
        \end{itemize}
    \item аналитический модуль:
         \begin{itemize}
            \item \verb|FuncAtPoint| (анализ характеристик поля);
            \item \verb|WaterProfile| (построение профилей).
        \end{itemize}
\end{enumerate}

Перспективным направлением развития является интеграция всех компонентов в единую программную платформу \verb|RRSPH|,
а также реализация вычислительного модуля, использующего CUDA для распараллеливания.
%
При разработке использовались стандарты C++17 и C++20~\cite{Gregoire2021, Savitch2016}. 
%
Для обеспечения кроссплатформенности применена система сборки CMake~\cite{Swidzinski2022}.
%
Проведено тестирование сборки в следующих средах:
\begin{itemize}
    \item IDE: Microsoft Visual Studio Community 2019/2022, Visual Studio Code;
    \item компиляторы: MSVC, Clang, MinGW GCC;
    \item системы: Windows 10/11, Linux (Ubuntu, Manjaro, Fedora), WSL (Ubuntu).
\end{itemize}

\section{Архитектура потоков данных в программном комплексе}
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

На рисунке~\ref{f:dfd} представлена диаграмма потоков данных (DFD), 
иллюстрирующая архитектуру взаимодействия компонентов программного комплекса. 
%
Диаграмма включает:
\begin{itemize}
    \item основные потоки данных;
    \item процессы обработки;
    \item хранилища данных.
\end{itemize}
%
\begin{figure}[h!]
    \centering
    \includegraphics[width=0.8\textwidth]{images/dfd2025.png}
    \caption{Диаграмма потоков данных программного комплекса RRSPH.}
    \label{f:dfd}
\end{figure}

Входные данные эксперимента представляют собой две сущности: параметров модели и начальных условий.
%
Параметры модели --- это файл \verb|ModelParams.json|, содержащий значения свободных параметров, таких как
используемые ядра сглаживания, методы обработки искусственной скорости звука, граничных условий, генератора волн,
вязкости. 
Такой файл можно подготовить вручную --- шаблон при установке копируется в директорию с документацией в качестве примера.
Разрабатывается также инструмент --- \verb|RRSPH_GUI|, позволяющий редактировать параметры модели в браузере 
(в качестве основной технологии выбран язык python и библиотека streamlit для визуализации).
%
Начальные условия состоят из двух файлов --- файла с описанием частиц 
(таблица со значениями $\vec{r}_{i}$, $\vec{v}_i$, $\rho_i$ и типами частиц), 
а также файла \verb|ParticleParams.json|, который содержит информацию о моделируемой области, границах и параметрах среды.
Данные файлы обычно генерируются с помощью python-скриптов, исходя из геометрии эксперимента,
либо из фактических данных, которые конвертируются в исходный временной слой частиц.

Далее происходит моделирования жидкости выбранной программой на основании указанных входных данных.
%
Результатом моделирования являются файлы, содержащие список всех частиц: их состояние и позицию. 
%
Каждый файл описывает отдельный временной слой, в названии указывается его номер.

Данные временных слоёв хранятся в формате CSV и обрабатываются специализированной библиотекой \verb|RRSPH_FIO|.

Аналитические модули выполняют следующие функции:
\begin{itemize}
    \item \verb|FuncAtPoint| --- вычисление временных зависимостей характеристик поля в заданной точке;
    \item \verb|WaterProfile| --- построение пространственных или временных профилей жидкости.
\end{itemize}

Модуль \verb|SPH2D_Drawer| обеспечивает:
\begin{itemize}
    \item визуализацию частиц;
    \item генерацию тепловых карт;
    \item создание анимационных последовательностей (с помощью ffmpeg).
\end{itemize}

Модуль \verb|Scatter3D| способен выполнять визуализацию большого количества частиц в пространстве,
а также создавать анимационные последовательности (с помощью ffmpeg).

Для преобразования временных слоёв в сеточное представление используется модуль \verb|PartToGridConverter|.
%
Полученные с его помощью данные можно далее обрабатывать разнообразными сторонними инструментами.

Существуют также конфигурационные файлы, регулирующие работу приложений, которые не отображены на диаграмме. 
Каждое приложение может использовать такой файл для быстрого изменения своего поведения.

\section{Вычислительная часть комплекса ПО для моделирования динамики жидкости}
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

Разработанные программы используют параллельные технологии OpenMP и OpenCL, 
что позволяет значительно ускорить процесс вычислений, 
так как моделирование динамики жидкости методом SPH является задачей массового параллелизма.

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\subsection{Разбиение вычислительной части ПО на модули}
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

В программе \verb|RRSPH_OMP| 11 модулей написанных в процедурном стиле:
%
\begin{enumerate}
    \item \verb|TimeIntegration| (шаги и полушаги по времени);
    \item \verb|UpdateAcceleration| (пересчёт всех параметров для одного шага по времени);
    \item \verb|SmoothingKernel| (ядра сглаживания);
    \item \verb|Density| (вычисление плотности с помощью уравнения непрерывности, либо сглаживанием массы);
    \item \verb|InternalForce| (внутренние силы --- вязкость и давление);
    \item \verb|ArtificialViscosity| (искусственная вязкость);
    \item \verb|ExternalForce| (внешние силы --- сила тяжести и силы взаимодействия с границами);
    \item \verb|AverageVelocity| (усреднение скорости);
    \item \verb|WaveMaker| (генераторы волн);
    \item \verb|EOS| (уравнения состояния);
    \item \verb|GridFind| (NNPS, поиск пар взаимодействющих частиц с помощью сетки).
\end{enumerate}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\subsection{Реализация численных методов в вычислительных модулях}
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

Основная часть исходного кода является общей для обоих вычислительных модулей. 
%
Исходный код для \verb|RRSPH_OMP| реализован в виде шаблонного кода на C++.
Условные конструкции обрабатываются динамически, 
а постоянные для конкретного эксперимента параметры вычисляются во время выполнения.
%
Вычислительные ядра OpenCL C исходного кода \verb|RRSPH_CL| компилируются непосредственно во время работы основного приложения, 
что позволяет оптимизировать вычисления за счет предварительного разрешения условных конструкций и вычисления константных выражений.
%
Интеграция таких разных модулей за счёт препроцессора позволила снизить риск расхождения реализаций и возникновения
различных ошибок, которые далее было бы проблематично исправлять.

%%%%%%%%%%%%%%%%%%%%%%%
\subsubsection{Модуль временного интегрирования}
%%%%%%%%%%%%%%%%%%%%%%%

Модуль \verb|TimeIntegration| реализует схему интегрирования по времени методом Leapfrog (рисунок~\ref{f:SPH2D_scheme1}). 
%
Алгоритм состоит из следующих этапов~\cite{Liu2003}:
\begin{enumerate}
    \item Первый шаг выполняется по системе уравнений:
    %
    \begin{equation}\label{eq:leapfrog0}
        \begin{cases}
            t = t_{0} + \Delta t, 
            \\
            \rho_{i}(t_{0} + 0.5 \Delta t) = \rho_{i}(t_{0}) + 0.5 \Delta t \cdot D\rho_{i}(t_{0}),
            \\
            \vec{v}_{i}(t_{0} + 0.5 \Delta t) = \vec{v}_{i}(t_{0}) + 0.5 \Delta t  \cdot D\vec{v}_{i}(t_{0}),
            \\
            \vec{r}_{i}(t_{0} + \Delta t) = \vec{r}_{i}(t_{0}) + \Delta t \cdot \vec{v}_{i}(t_{0}+0.5\Delta t).
        \end{cases} 
    \end{equation}

    \item На каждой итерации сначала выполняется полшага для плотности и скорости (функция \verb|PredictHalfStep|):
    %
    \begin{equation}\label{eq:leapfrog1}
        \begin{cases}
            \rho_{i}(t) = \rho_{i}(t - 0.5 \Delta t) + 0.5 \Delta t \cdot D\rho_{i}(t - \Delta t),
            \\
            \vec{v}_{i}(t) = \vec{v}_{i}(t - 0.5 \Delta t) + 0.5 \Delta t \cdot D\vec{v}_{i}(t - \Delta t).
        \end{cases} 
    \end{equation}

    \item Затем вычисляются производные и выполняется полный шаг интегрирования (функция \verb|WholeStep|):
    \begin{equation}\label{eq:leapfrog2}
        \begin{cases}
            t = t + \Delta t, 
            \\
            \rho_{i}(t + 0.5 \Delta t) = \rho_{i}(t - 0.5 \Delta t) + \Delta t \cdot D\rho_{i}(t),
            \\
            \vec{v}_{i}(t + 0.5 \Delta t) = \vec{v}_{i}(t - 0.5 \Delta t) + \Delta t \cdot D\vec{v}_{i}(t),
            \\
            \vec{r}_{i}(t + \Delta t) = \vec{r}_{i}(t) + \Delta t \cdot \vec{v}_{i}(t+0.5\Delta t).
        \end{cases} 
    \end{equation}
\end{enumerate}
%
Итерационный процесс продолжается до достижения конечного времени моделирования $t \geq t_{\text{max}}$.

\subsubsection{Модуль сглаживающих ядер}

%%%%%%%%%%%%%%%%%%%%%%%
\subsubsection{Модуль внутренних сил}
%%%%%%%%%%%%%%%%%%%%%%%
Модуль \verb|InternalForce| вычисляет правую часть уравнения движения частиц:
%
\begin{equation}
    \frac{D\vec{v}_{i}}{Dt} = -\sum\limits_{j}m_{j}\left(
    \frac{p_{j}}{\rho_{j}^{2}} +
    \frac{p_{i}}{\rho_{i}^{2}}
    \right) \nabla_{i} W_{ij} + \vec{g} + F^{(visc)}.
\end{equation}
%
Реализованы альтернативные формы представления:
\begin{equation}
    \frac{D\vec{v}_{i}}{Dt} = -\sum\limits_{j}m_{j}\left(
    \frac{p_{j} + p_{i}}{\rho_{j}\rho_{i}}
    \right) \nabla_{i} W_{ij} + \vec{g} + F^{(visc)}.
\end{equation}
%
Модуль поддерживает настройку параметров вязкости и искусственного давления, что влияет на стабильность численного решения.

\subsubsection{Дополнительные модули}
\begin{itemize}
    \item \verb|ArtificialViscosity|: расчёт искусственной вязкости (уравнение~\ref{eq:art_visc});
    \item \verb|AverageVelocity|: усреднение скорости по схеме XSPH (уравнение~\ref{eq:xsph});
    \item \verb|ExternalForce|: реализация граничных условий (метод динамических частиц и метод отталкивающих частиц, уравнение~\ref{eq:sbt1});
    \item \verb|WaveMaker|: генератор волн в виде поршня.

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\subsection{Модули поиска пар взаимодействующих частиц}
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

Поиск пар взаимодействующих частиц представляет собой вычислительно сложную часть реализации метода SPH. 
%
Полный перебор всех возможных пар частиц со сложностью $O(N^2)$ 
приемлем только для задач с небольшим количеством частиц (порядка $10^2-10^3$). 
%
Для крупномасштабных симуляций с числом частиц более $10^5$ требуются эффективные алгоритмы с пониженной вычислительной сложностью.

%%%%%%%%%%%%%%%%%%%%%
\subsubsection{Сравнение методов пространственного поиска}
%%%%%%%%%%%%%%%%%%%%%

В современных реализациях SPH применяются два основных класса алгоритмов:

\begin{itemize}
    \item Сеточные методы (grid-based), обладающие сложностью $O(N)$ 
        в оптимальном случае~\cite{Xia2016, Morillo2015, Nie2014, Monaghan1985}. 
        Эти методы особенно эффективны для:
    \begin{itemize}
        \item задач с постоянной длиной сглаживания $h$,
        \item моделирования несжимаемых сред,
        \item высокопараллельных реализаций~\cite{Gross2019}.
    \end{itemize}
    
    \item Древовидные структуры (квадро-/октодеревья)~\cite{Xia2016} со сложностью $O(N\log N)$, которые предпочтительны для:
    \begin{itemize}
        \item задач с переменной длиной сглаживания,
        \item моделирования сжимаемых сред (газов),
        \item случаев с неравномерным распределением частиц.
    \end{itemize}
\end{itemize}

%%%%%%%%%%%%%%%%%%%%%
\subsubsection{Реализация сеточного метода}
%%%%%%%%%%%%%%%%%%%%%

В программе \verb|RRSPH_OMP| реализован последовательный вариант сеточного алгоритма, включающий следующие компоненты:

\begin{itemize}
    \item массив \verb|grid| --- частицы, отсортированные по принадлежности к ячейкам, используется сортировка подсчётом;
    \item массив \verb|cells| --- хэш-таблица, содержащая индексы начала частиц для каждой ячейки,
        которая является побочным эффектом алгоритма сортировки.
\end{itemize}

Размер ячейки сетки определяется как $kh$, где $h$ --- длина сглаживания, 
а $k$ --- коэффициент дальнодействия ядра (3 для Гауссова ядра, 2 для других ядер). 
%
Пространственная локализация частиц иллюстрируется на рисунке~\ref{f:searchcells}.

\begin{figure}[h!]
    \centering
    \includegraphics[width=0.5\textwidth]{images/cells_to_search.png}
    \caption{Геометрия поиска соседних частиц в сеточном методе~\cite{Xia2016}.}
    \label{f:searchcells}
\end{figure}

Для эффективного хеширования многомерных координат ячеек используются z-кривые (кривые Мортона)~\cite{Xia2016}.

%%%%%%%%%%%%%%%%%%%%%
\subsubsection{Параллельная реализация для GPU}
%%%%%%%%%%%%%%%%%%%%%

В GPU-версии вычислителя, \verb|RRSPH_CL|, применены следующие оптимизации:

\begin{itemize}
    \item параллельная сортировка частиц непосредственно на GPU (избегание дорогостоящих операций передачи данных),
        используется метод битонной сортировки;
    \item генерация массива \verb|cells| с помощью бинарного поиска;
    \item распределённая обработка соседних ячеек:
    \begin{enumerate}
        \item определение текущей ячейки частицы,
        \item вычисление соседних ячеек,
        \item поиск кандидатов в соседи с проверкой расстояния $r_{ij} < kh$.
    \end{enumerate}
\end{itemize}
%
Предложенная реализация демонстрирует высокую эффективность при работе с большим количеством частиц.

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\subsection{Пользовательский интерфейс и файловая структура вычислительного комплекса RRSPH}
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

Модуль ввода-вывода \verb|RRSPH_FIO| обеспечивает интерфейс взаимодействия с пользователем 
и эффективную работу с временными слоями в вычислительном комплексе.

%%%%%%%%%%%%%%%%%%%%%
\subsubsection{Организация пользовательского интерфейса}
%%%%%%%%%%%%%%%%%%%%%

Реализован интерфейс командной строки со следующими функциональными возможностями:

\begin{itemize}
    \item Интерактивное создание нового эксперимента:
    \begin{itemize}
        \item инициализация директорий и конфигурационных файлов;
        \item анализ директорий с экспериментами и вывод статистики по временным слоям и точкам сохранения;
        \item запуск расчёта из подходящей директории.
    \end{itemize}
    
    \item Продолжение прерванных расчетов:
    \begin{itemize}
        \item возобновление с последнего временного слоя;
        \item рестарт с заданной точки сохранения;
        \item полный перезапуск с исходными условиями.
    \end{itemize}
    
    \item Мониторинг длительных вычислений:
    \begin{itemize}
        \item отображение затраченного времени;
        \item вывод в лог статистики по времени работы вычислительных ядер;
        \item прогнозирование времени завершения.
    \end{itemize}
\end{itemize}

%%%%%%%%%%%%%%%%%%%%%
\subsubsection{Файловая структура RRSPH}
%%%%%%%%%%%%%%%%%%%%%

Ниже, в листинге~\ref{lst:files} представлена структура основной директории RRSPH. 
%
В корне расположены исполняемые файлы вычислителей и обработчиков, а также
директория \verb|cl| с исходным кодом вычислительных ядер для \verb|RRSPH_CL|.

\subsection{Двумерная визуализация частиц}
%%%%%%%%%%%%%%%%%%%%%

Программа для моделирования выдаёт данные в виде множества файлов, 
в которых описано состояние всех частиц для всех слоёв, кратных шагу сохранения.
%
В самом простом случае требуется вывести положение частиц среды в разные моменты времени. 
%
Может потребоваться вывести свойства частиц в виде их цвета, тогда строится тепловая карта.
%
Для вывода таких данных в виде частиц используется \verb|SPH2D_Drawer|.

Эта программа была разработана на языке C++ 20 стандарта~\cite{Gregoire2021} 
с использованием графической библиотеки \verb|SDL2|~\cite{Mitchell2013}, 
библиотеки \verb|nlohman/json| для чтения файла конфигурации и 
библиотеки \verb|csv-parser| для быстрого чтения данных с помощью проецирования файла в память.
%
За основу были взяты наработки в области разработки игр на \verb|SDL2|~\cite{Mitchell2013}. 
Программа разделена на составляющие, отвечающие за данные, выводимые на экран, 
обработку ввода в реальном времени и сам вывод на экран --- по схеме Model-View-Controller.

Существует возможность масштабирования, перемещения по координатам, перемещения по времени, проигрывания анимации динамики жидкости, 
регулировка скорости проигрывания, приостановки, записи видео или отдельных кадров с помощью горячих клавиш.

Для более тонкой настройки добавлена система команд, позволяющая редактировать большинство переменных.
%
Чтобы ускорить настройку отображения результатов моделирования, добавлена возможность загружать настройки из файлов конфигурации.

Помимо самих частиц выводится время от начала эксперимента, а также легенда, если включена тепловая карта.
%
Тепловая карта позволяет выбрать, по какому свойству задавать цвет частицы, а также границы этого свойства.

%%%%%%%%%%%%%%%%%%%%%
\subsection{Трёхмерная визуализация частиц}
%%%%%%%%%%%%%%%%%%%%%

Для трёхмерной визуализации потребовалась более сложная система управления и отрисовки.
%
Одним из основных требований к программе визуализации является возможность чтения файлов временных слоёв
во время моделирования, без промежуточных преобразований.
%
Также сложность представляет количество частиц, которые требуется визуализировать (зачастую это миллионы частиц) и
поддерживать отзывчивый интерфейс с поддержкой функций перемещения, вращения и масштабирования.

Было принято решение использовать python и библиотеку vispy для производительной визуализации и управления.
%
В отличие от большинства других библиотек, она позволяет визуализировать частицы в виде точек в пространстве (scatter),
что позволяет эффективно их отображать.
%
Разработанная программа \verb|Scatter3D| помимо описанных выше функций поддерживает проигрывание анимации динамики жидкости, 
делать скриншоты и записывать видео.

\subsection{Модуль анализа полевых величин в точке}
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

Программный модуль \verb|FuncAtPoint| предназначен для вычисления зависимости скалярных или векторных полей 
(например, давления или скорости)
в произвольной пространственной точке от времени.
%
Алгоритм модуля основан на SPH-аппроксимации (уравнение~\ref{eq:sph_approx}), 
применяемой к частицам в окрестности целевой точки на каждом временном шаге.

Реализация поддерживает два режима работы:
\begin{itemize}
    \item интерактивный консольный интерфейс с пошаговым вводом параметров;
    \item пакетный режим с передачей аргументов через командную строку (для обработки аргументов используется
    библиотека \verb|cxxopts|, поддерживающая позиционные и именованные параметры).
\end{itemize}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\subsection{Модуль реконструкции профиля поверхности жидкости}
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

Для анализа волновых процессов критически важна реконструкция свободной поверхности жидкости.
%
Модуль \verb|WaterProfile| обеспечивает анализ свободной поверхности жидоксти в двух режимах:
\begin{itemize}
    \item пространственный профиль (распределение высоты поверхности вдоль заданной координаты)
    в фиксированный момент времени;
    \item временной профиль (эволюция высоты поверхности в заданной пространственной точке в течение всего времени моделирования).
\end{itemize}

Алгоритм работы модуля включает следующие этапы:
\begin{enumerate}
    \item выборка частиц в окрестности целевой точки или вдоль заданной координаты с учётом радиуса сглаживания;
    \item определение поверхности через выделение частиц с максимальными значениями высоты в области;
    \item реконструкция профиля с помощью усреднения высот (общий случай),
        либо полиномиальной регрессии и поиска максимума параболы методом наименьших квадратов (для определения пиков волн).
\end{enumerate}

Для обработки больших объёмов данных код параллелизован с использованием OpenMP.
конфигурация модуля задаётся через JSON-файл, что позволяет задать общую программу замеров для серии экспериментов.
